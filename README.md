# Router Unit

Phase 1 contains only the pure Router API prerequisite. The five API files
(`api/Cargo.toml`, `api/src/lib.rs`, `api/src/declaration.rs`, `api/src/frame.rs`,
`api/src/marks.rs`) are the exact original Source `293c15fc…` Router API files
and must remain byte-identical.

This repository does **not** claim that the Router runtime has moved. Router
server/client implementation and runtime ownership remain Source and are pending
Unit intake. No fake server, client, declaration, UnitFile, or runtime image is
present here.

The public repository is `shuyra-arche/router`, verified available and pushable.
Consumers use the complete published revision after public clean-checkout proof;
no placeholder revision or local path back-link to Driver/Source is used.
The API is a pure prerequisite for the Hub Unit. Root owns provenance,
hashes, generated locks, native/public proof, and publication.
